# AWS Solutions Architect – Hands-on Practice

A collection of hands-on labs completed while preparing for the **AWS Certified Solutions Architect – Associate (SAA-C03)** certification.

This repository documents practical AWS exercises through console screenshots, short notes, and selected CLI or architecture references. Resources were created for learning and experimentation, then removed when no longer needed.
